# Dashboard Grafik Rental Sepeda

Proyek pembelajaran analisis data yang berfungsi untuk mengelompokkan serta menampilkan sebuah data beserta grafiknya sebagai berikut:
1. Menampilkan pemesanan tahunan rental sepeda berdasarkan cuaca
2. Perbandingan rata-rata jumlah pelanggan casual dan registered (terdaftar) per tahun

Semua dikerjakan dengan menggunakan Python.
